# AGENTS.md

Канонический файл инструкций для любого агента (Claude и др.), работающего в этом Obsidian-хранилище.

## Назначение хранилища

Иван учится играть на гитаре и петь. Хранилище — не дневник и не курс, а **база знаний для тренировки**: каждая заметка — минимальная самодостаточная единица, которую можно открыть и сразу тренировать, без гугления.

Темы: интервалы, тональности, аккорды, песни, теория (короткие объяснения непонятных понятий). Пение фиксируется только внутри разбора песен, как поддержка гитары, а не отдельная тема.

## Жёсткие правила

- **Никогда не делай `git commit` / `git push` / `git add` сам.** Коммитит только Иван руками. Можно оставлять файлы изменёнными/незакоммиченными сколько угодно.
- **Минимум текста.** Схемы, таблицы, диаграммы грифа (ASCII), нотные обозначения — да. Абзацы прозы — нет, кроме одной-двух строк, если без них не обойтись.
- Каждая заметка — **одна сущность** (один интервал / одна тональность / один аккорд / одна песня / одно понятие теории), со своим frontmatter.
- Прежде чем создавать или редактировать заметку конкретного типа, прочитай соответствующий файл в `agents/` — там протокол именно для этого типа.
- Ноты (до-ре-ми) отдельной темы не имеют — вводятся попутно, где встречаются (составы аккордов, тональности).
- Аккорды и тональности носят русские названия внутри заметки, но **английские имена файлов**: аккорды — короткий символ (`C.md`, `Am.md`, `F.md`), тональности — полное название (`C major.md`, `A minor.md`). Так имена не пересекаются между папками.

## Структура

```
guitar/
├── AGENTS.md                — этот файл
├── CLAUDE.md                 — тонкая прослойка для Claude, отсылает сюда
├── Дашборд.base              — сводка "что освоено" по всему хранилищу
├── agents/                   — протоколы для агентов по типам заметок (папка не переводится)
│   ├── vault-conventions.md
│   ├── theory-note.md        — интервалы и тональности
│   ├── chord-note.md         — аккорды
│   └── song-analysis.md      — разбор песен (самое важное и подробное)
├── Интервалы/                 — заметки об интервалах + Интервалы.base
├── Тональности/                — заметки о тональностях + Тональности.base
├── Аккорды/                    — заметки об аккордах + Аккорды.base
├── Песни/                      — разборы песен + Песни.base
└── Теория/                     — объяснения непонятных понятий (напр. "Ступени")
```

## Общая схема frontmatter

Во всех заметках-сущностях (interval/key/chord/song) обязательно есть:

```yaml
type: interval | key | chord | song | theory
mastered: false   # bool, меняет только Иван вручную
```

`mastered` — единственный "прогресс"-сигнал в вольте. Отдельного журнала/лога дат нет и не нужно: мотивация — сам факт отметки "освоено" в дашборде.

## Дашборды (Obsidian Bases)

`.base`-файлы (корневой `Дашборд.base` и по одному в каждой папке) — это core-плагин Obsidian **Bases** (не требует установки Dataview). Они строят таблицы/группировки прямо по frontmatter. Если добавляешь новый тип заметки или новое свойство — проверь, что оно совместимо с фильтрами в соответствующих `.base` файлах.

## Связи

Аккорды и тональности, упомянутые в песне, должны быть оформлены как `[[Wikilink]]` (например `[[C]]`, `[[G major]]`). Тогда Obsidian сам построит обратные ссылки — не нужно вручную вести список "в каких песнях используется этот аккорд/тональность".
